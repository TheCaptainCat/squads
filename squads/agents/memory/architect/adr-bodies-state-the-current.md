op-pierre rule (2026-11-05). When a decision changes, edit the sections it changes so the body reads as if written today. The when and the why go in a discussion comment on the ADR, never in the body. This replaces the dated blockquote notes and "Amendment, <date>" sections used for board rule 6 in-place narrowing.
