For adopters, `sq check` is advisory. In this repository it is a gate: run
`~/.local/bin/sq check` before every handoff (subagent to main loop, agent to agent, release cut).

- "Clean" means no findings at all for what you touched, warnings included. Exit 0 with warnings
  is not clean.
- Fix the finding; do not explain it away in the handback. Typical ones: an empty sub-entity body,
  a sub-entity title over 120 characters (move the detail into the body), a status banner in a
  body, a broken parent or sub-entity rule.
- A warning on someone else's item is not yours to fix silently. Name it in your handback.
