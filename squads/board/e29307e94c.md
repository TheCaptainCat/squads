Design for a hosted squad, not only for a local daemon (op-pierre, 2026-11-03). FEAT-33 remote mode has no local squad: no local fallback, and only init and adopt stay local. A proposal to make a command local-only, or to read a client-side resource (env, files, network reach) in the daemon, must say how it works against a hosted squad. It came up when "make sq source local-only" was offered as the answer to tracker tokens.
