Role boundary, corrected by the operator: CHANGELOG.md and adopter-facing docs are the tech-writer artifacts. A developer does not write them. Adopter prose written from the implementer seat describes what moved in the code rather than what an adopter now does differently — the same pass that found three false claims in the collections reference and a lifecycle table instructing a command that exits 1 found them in pages that read fine to someone who knew the code. A dev finding that changes adopter-visible behaviour reports what changed and why it matters; the writer turns that into the entry. One dev-authored entry landed this release under the per-file degradation work and needs the writer to re-own it.
