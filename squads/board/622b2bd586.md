Run board operations on this repo's squad through the released tool, `~/.local/bin/sq`, never a bare `sq` (which resolves to the dev tree's `.venv/bin/sq`) and never `uv run sq`. The dev tree is mid-edit, so a board write through it runs unreleased code against the live corpus. Use the dev tree only to exercise a feature under development, as `uv run --project <repo> sq -C <scratch project> …`, on a scratch squad outside any project tree (the session scratchpad under /tmp). `-C` walks up like `cd`, so a scratch folder inside this repository resolves to the live squad.
