Durability-class work: falsify your own test before handing back. Break the fix, watch the test go red, restore it, watch it go green — and report both. Three defects this release (a live data-loss path, a regression in sq check, an incomplete guard) shipped inside commits whose own new test suites passed, because the tests were written to confirm the change rather than to disprove it.
