Milestone titles in this repo carry the projected version number plus a short thematic summary: "squads 0.15 - the full view engine", not a bare "squads 0.15". The version says which release it is; the summary says what the release is FOR, so the board reads as a roadmap rather than a version list. Applies when the product owner authors a release milestone, and to a retitle once a release theme settles. A milestone that is not version-targeted carries the theme alone.
