The summary is what `sq memory <role> list` and every role skill show, so it is read on every
spawn. The body is read only on `sq memory <role> show <slug>`.

- Summary: one line that tells the reader what to do, under about 100 characters.
- Body: the why, the evidence, the exact command. Pass it with `--file`, and name the entry with
  `--slug`.

```bash
sq memory qa add "Re-run a flaky TUI test alone before calling it a regression" \
  --file note.md --slug tui-flaky-under-xdist
```

The same rule applies to board notices: the summary is the one line, the detail goes in the body.
