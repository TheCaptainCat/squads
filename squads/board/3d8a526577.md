Never sweep a shared temp namespace by glob. An agent purging test fixtures ran 'rm -rf /tmp/tmp.*' — a wildcard over the whole /tmp namespace, which is exactly where 'mktemp -d' puts its directories by default, so it could have destroyed any other process's temp data on this machine. Nothing of ours was lost: our scratchpad lives under a session-specific path, not /tmp/tmp.*, and the work itself was clean. Delete only a specific named path you created yourself. If you need scratch space, use the session scratchpad the harness provides, and remove exactly what you made — never a glob.
