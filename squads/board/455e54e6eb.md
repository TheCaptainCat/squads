We do not set target dates on release milestones. A release ships when it is ready, not on a date. Do not set target_date on a release milestone, and do not derive a schedule or a deadline from velocity when scoping one -- size the work and say what gates what, which is the useful part. Sequencing and dependency order still matter; calendar commitments do not.
